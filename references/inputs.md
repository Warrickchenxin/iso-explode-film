# 输入：有什么用什么

## 四档输入

| 档 | 文件 | 工具 | 精度 |
|---|---|---|---|
| A 精确模型 | STEP/STP、IGES；SolidWorks、Fusion、Creo、Onshape 导出的装配体 | `scripts/cad_inventory.py` | 零件和尺寸直接读出 |
| B 网格模型 | STL、OBJ、3MF、GLB/GLTF、PLY（3D 打印文件、电商 3D 展示、模型网站） | `scripts/mesh_inventory.py` | 尺寸准；分层和零件名要人工确认 |
| C 图纸 | DXF/DWG、PDF 工程图、规格书尺寸表 | 人工读图 | 按图纸尺寸搭；内部结构参照拆解资料 |
| D 照片 / 只有名字 | 产品照片、拆解图、官网参数 | 搜索 + 估算 | 用一个已知尺寸（接口、按键、螺丝）推算其余尺寸 |

一个产品可以混用几档。比如外壳用 STEP，PCB 用 DXF 线稿印到板面上，电池按拆解照片估尺寸。

### A 档：STEP / IGES

```bash
pip install cadquery-ocp numpy scipy pillow
python3 scripts/cad_inventory.py model.step inv/ [--level-x 5.26] [--glb]
```

- `parts.json`：每个实体一条，包括名称、装配路径、包围盒、尺寸、体积、面数、颜色、俯视凸包（mm）。
- `summary.txt`：
  - **层候选**：按 z 分段的实体；
  - **阵列候选**：同尺寸、4 份以上的实体；
  - 最大的实体（壳体、板）；
  - 用到的颜色。
- `plan.png`：俯视图，凸包按高度着色，用来核对布局。
- `side.png`：正视图，用来核对层叠关系。
- `--level-x/--level-y`：模型本身是倾斜的就先摆平。例如键盘 CAD 自带 5.26° 倾角。

大文件（几十 MB）要读几分钟。读出来的实体动辄上千个，不用每个都建模：
- 不可见的小件（螺丝内部、导线）跳过；
- 一组重复件建一个，再按坐标阵列；
- 弯曲的大件（外壳）按截面拆成几块凸块；
- PCB 的走线、元件丝印用 `planeTop` 印在板面上。

### B 档：网格

```bash
pip install trimesh numpy scipy pillow
python3 scripts/mesh_inventory.py model.glb inv/ [--split] [--scale 25.4] [--up y]
```

- 模型整体小于 5 个单位时，按米制自动 ×1000。
- CAD 导出的 GLB 常常一个面一个节点：节点超过 2000 个时，按父节点自动合并。
- 单个 STL 是一整块网格时，加 `--split` 按连通块拆开。
- 先看 summary 第一行的总尺寸：高度落在 Y 轴上，就加 `--up y`。

### C、D 档

- 先找一个能确定的尺寸作锚点：USB-C 口宽 8.9 mm，标准键帽 18 mm，M2 螺丝头 3.5–4 mm，18650 电芯 Φ18 × 65 mm。
- 内部结构优先找拆解资料（iFixit、拆解视频、评测图）；找不到就按同类产品的常规结构做，并在交付说明里写明。

## 产品规格单（建模前给用户确认）

```
产品：PB-1 移动电源      总尺寸：150 × 72 × 28.6 mm     来源：D 档（官网参数 + 拆解图估算）
层（从上到下）：上壳 / 导光条 / 电芯 / 支架 / 主板 / 导热垫 / 底壳   —— 7 层
阵列：电芯 ×8（电芯层）；主板元件 ×24（主板层）
核心零件：按键模块（键帽 · 硅胶碗 · 轻触开关 · 底座），拆成 4 件
机构动作：按键下压 1.6 mm
参数字卡：20000 mAh · 65 W · 1.6 mm
配色：石墨灰外壳，按键用唯一的强调色（红），电芯蓝
```

要点：
- **层**：5–10 层最好看。太少不像"大片"，太多每层只闪一下。相邻的薄片（两层泡棉）可以合成一层。
- **阵列**：至少要有一组几十个以上的重复零件（键帽、轴体、电芯、散热鳍片、LED、螺丝），"几百个零件炸开"的冲击感就靠它。
- **核心零件**：选能拆成 3–6 个子件、尺寸 5–40 mm 的零件，用来做特写。
- **机构**：按、转、滑、翻、开合都行；没有就让核心零件只拆不动，分镜里去掉 action 镜头。
- **参数**：只挑三到五个最有记忆点的数字，大数字用"万、亿"。

## 坐标约定

- 物体坐标：X 向右，Y 朝向观众，z 向上，单位 mm，原点在物体中心、底面 z = 0。
- kit 的世界坐标 x = −X（rig 的 `vx()` 已经处理）。`FILM.bounds` 用世界坐标写。
- `FILM.radius` ≈ 0.8 × 包围盒对角线。所有机位、爆炸距离、余量都按它缩放。

## 授权

- 厂商公开的 CAD 一般只允许个人或展示用途：成片可以发，模型数据和由它导出的文件不要分发。
- 片尾只打型号，不放品牌 logo 和商标。
