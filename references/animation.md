# 动画规则

## 通道

所有动作都由 8 个特征通道驱动（`object/film.mjs` → `featureValues`）。分镜生成器只写这些通道，不直接写零件。

| 通道 | 取值 | 作用 |
|---|---|---|
| `lift` | 0–1 | 整体离开桌面，抬高 0.15 × radius |
| `ex` | 0–层数 | 第 i 层在 ex 从 i 走到 i+1 时抬起（缓入缓出） |
| `burst` | 0–阵列数 | 第 j 个阵列在 burst 从 j 走到 j+1 时飞散；每个阵列分三圈，相互错开 0.4 |
| `wave` | −1 关闭；≥0 为时间 | 阵列波浪：8 个分组，每 0.5 秒一组 |
| `pull` | 0–1 | 核心零件抽出 |
| `split` | 0–子件数 | 子件依次拆开 |
| `hover` | 0–1 | 核心零件回落一段 |
| `act` | 0–1 | 机构动作 |

## 生成器保证的顺序（`motion/timeline.mjs`）

- **每个镜头开头先把所有通道钉在当前值**（hold），避免上一个镜头的值在镜头之间慢慢漂移。
- **收拢先收阵列，再合层**：part 镜头开头 0.12 秒先让 burst 归零，甩镜过程中再合层。反过来做的话，下落的层会砸进还没收回的阵列。
- **展开先分层，再飞散**：array、stack 镜头甩镜时只把 ex 拉开，burst 保持原值；镜头到位后 0.65 秒内阵列才飞散。
- **合拢从下往上**：assemble 镜头里各层按从下到上的顺序落回；每个阵列在自己那层落位之前收回。
- **爆炸时阵列跟着自己的层走**：阵列 j 在它那一层抬起的时间段里飞散；同一层有两个阵列时依次错开。
- **甩镜**：0.25–0.3 秒，五次方缓动。甩镜期间运动模糊最多 12 个子帧，所以甩镜中间的帧看不出两件零件交错的瞬间，但 `scan.mjs` 照样会报，要处理掉。

## 自己加镜头或改顺序时

1. 新镜头在 `timeline.mjs` 的 beat 循环里加一个分支，并且只写通道和机位。
2. 开头留着 `hold(t0)`；甩镜关键帧的 `ease: "whip"` 时长保持 0.25–0.35 s。
3. 往 `EVENTS` 里加音效提示（`tap / spray / thud / whoosh / riser / boom / drop`），往 `CARDS0` 里加字卡，低机位镜头往 `MARGINS0` 里加渲染余量（2.1–2.7）。
4. 重新 build 两个 look，再跑 `scan.mjs`，直到 clean。

## 运镜原则

- 一镜到底：不硬切。停留时镜头也要漂移（yaw 变 5–35°，zoom 变 3–8%），只有最后半秒完全静止。
- 爆炸状态整体居中、不出框。爆炸机位 EXV 的焦点在"主体中心 + lift + 0.85 × radius"，各层默认行程刚好落在这个画面里。
- 特写镜头里主体要完整，字卡不能压住主体。
- 节奏对齐 120 BPM：层落位、按键都落在 1/4 拍上。
