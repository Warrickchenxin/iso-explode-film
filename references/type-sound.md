# 字卡、层标注、声音

## 字体

- 鸿蒙黑体 SC（HarmonyOS Sans SC）Thin / Light / Regular。`bash film/get_fonts.sh` 会从 GitHub 下载 woff2 并转成 TTF，放进 `film/fonts/`。
- 下载不了时，`render_film.py` 自动退回系统里的 Noto Sans CJK、苹方或微软雅黑。

## 字卡（`render_film.py` → `draw_cards`）

- 字卡来自 `plan.json` 的 `cards`，由 `story.mjs` 生成，不用手写时间。
- 入场：0.35 秒上移 18 px 加淡入；出场淡出 0.18 秒。
- 橙色版用深墨色 (24,24,27)，小字 (88,88,94)；黑色版用暖白 (248,246,242)，小字 (226,222,214)。

## 层标注（`draw_labels`）

- 只在 explode 镜头里出现。每层一条：
  - 圆点钉在这一层左前方的一个点上（rig 按这一层零件的包围盒算出来）；
  - 细线拉到右侧 x = 1460 的标注列；
  - 中文用 Regular 32 px，英文小字用 Light 15 px。
- 圆点跟着这一层实时移动：位移 = 层通道 + lift + 同层阵列中圈的上升量。位置用和物体同一个透视单应矩阵变换，所以不会指错层。
- 某一层抬起超过行程的 60% 时，它的标注才完全显出来。
- 各行之间至少隔 34 px，挤在一起时按顺序往下推，用折线连过去。

## 声音（`film/synth.py`）

全部用代码合成，48 kHz 立体声，A 小调 Am–F–C–G，每两小节换一个和弦，120 BPM。**不用叮当、铃声这类提示音。**

| 镜头 | 底乐 |
|---|---|
| hero | pad，后半段加入踩镲和贝斯 |
| rise | pad，加上升音 |
| explode / array / stack | 第一、二次高潮：底鼓每拍一下，拍手每两拍一下，十六分音符踩镲，贝斯；array / stack 再加和弦短音 |
| part / action | 安静段：pad、轻底鼓、八分音符踩镲 |
| assemble | 拍手加速滚奏、贝斯、上升音 |
| end | 低频冲击 + 底鼓 + 一个长和弦尾音 |

| 提示 | 声音 |
|---|---|
| `tap` | 按键声：短促的咔嗒 + 低频"咚"，带深度参数，没有音高拖尾 |
| `spray` | 一串密集的小咔嗒，随机分布在左右声道（零件飞散或落回） |
| `thud` | 一层落位的闷响 |
| `whoosh` | 甩镜的呼啸 |
| `riser` | 噪声上升音 |
| `boom` / `drop` | 低频冲击 |

- 母带处理：25 Hz 高通，归一化后过 tanh 软限幅，最后 0.4 秒淡出。
- 用户自己提供音乐时：
  1. 量出音乐的 BPM，改 `STORY.bpm`；
  2. 把 beat 起点对到小节线；
  3. 渲染时不跑 synth，最后用 ffmpeg 混入用户的音乐，音效可以单独渲染一轨叠上去。

测试时不要用电脑扬声器外放声音。
