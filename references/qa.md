# 自检清单

每一项都要查，两个 look 都要查。前 4 项在建模和分镜阶段查，后面的看样帧和成片。

| # | 检查 | 方法 | 不通过怎么办 |
|---|---|---|---|
| 1 | **穿插**：任何两件零件不能互相穿过去 | `node motion/scan.mjs motion/motion-split.html` 输出 `every frame clean` | 从 0 秒起就穿插：改几何。只在某段动作里穿插：调动画顺序（`animation.md`） |
| 2 | **闪烁**：遮挡关系不能跳变 | 同上，不能有 forced picks | 补预算姿态；共面的零件抬高 0.05–0.3 mm |
| 3 | **尺寸**：总尺寸、零件数和规格单一致 | build 输出的零件数、`FILM.bounds`、figure 页 | 改几何 |
| 4 | **配色**：只有一个强调色，两个 look 下都看得清 | 交互页 `npm run figure` 转一圈 | 换材质 |
| 5 | **构图**：爆炸完全展开的那一帧居中、不出框，上下留白差不多 | 样帧：explode 镜头 75% 处和结尾 | 调 `EXV` 焦点偏移（0.85 × radius）或某一层的 `travel` |
| 6 | **主体完整**：特写、动作、阵列、夹层镜头里，主体没有被切掉一半，字卡不压主体 | 每个镜头抽中间和结尾两帧 | 镜头加 `cam` 覆盖：zoom 降 10–20%，或调 panX / panY |
| 7 | **渲染边界**：画面里不能出现一条直线把零件切掉 | 低机位镜头抽 3 帧 | 加大这一段的余量（2.1→2.7→3.2） |
| 8 | **标注**：每条都指在对应的层上，没有互相压住 | explode 镜头抽 3 帧 | 检查 `labelItems` 的 point / follow |
| 9 | **动作间隙**：按压、旋转时零件之间有缝 | action 镜头逐帧看最深的那一下 | 加大间隙或减小 `mech.travel` |
| 10 | **字卡时间**：字卡出现和镜头到位对得上，没有在甩镜中间出现 | 每张字卡出现后 0.1 秒的帧 | 调 `card()` 的起止时间 |
| 11 | **节奏**：层落位、按键和音效同步 | 带声成片看一遍（不要用扬声器外放） | 调 `EVENTS` |
| 12 | **成片**：MP4 本身没问题（不是只看了帧） | `out/check_*.jpg` 是从 MP4 抽帧拼的；再抽 2 个甩镜中间帧 | 重渲出问题的帧（删掉那几帧，重跑会自动补） |

## 抽帧命令

```bash
python3 film/render_film.py out/s --look split --frames 60,200,300,390,450,540,660,770,880
python3 film/contact_sheet.py out/s.jpg out/s/*.jpg --cols 3
python3 film/contact_sheet.py out/v.jpg out/PB-1_split.mp4 --times 1,7,11.5,13,15,17,21,26,29.5
```

交付时写明哪些项没有验证（比如没有在扬声器上听过声音、没有用 60 秒版本测过）。
